# Amazon-Clone

This is a **Clone of Amazon** website built using **HTML** and **CSS**.  
The project demonstrates layout design, product display, navigation bar, and responsive styling similar to the Amazon website.

## Live Demo

Check out the live project here:  
[Amazon-Clone Live](https://pratik-code7.github.io/Amazon-Clone/Amazon/)

## Features

- Fully responsive layout
- Navigation bar with search and cart section
- Product listing grid
- Hover effects on products
- Footer with links
